# 快速開發全端程式

## 1. 明確定義 MVP

- 核心功能、使用者角色、主要資料流程
- 先避免設計用不到的功能

## 2. 確認技術架構

- 前端框架、後端框架、資料庫
- API 形式、驗證方式、檔案儲存方案
- 建議選團隊熟悉且生態完整的技術，不只看熱門程度

## 3. 先建立 GitHub 儲存庫

- 初始化 Git、`.gitignore`、分支策略
- 設定 Issue／PR 模板與基本 CI
- 後續每個架構調整都有歷史紀錄

## 4. 建立專案骨架

- 分離 `frontend`、`backend`
- 建立環境變數範例，例如 `.env.example`
- 加入 lint、formatter、型別檢查與基本測試

## 5. 建立 Docker Compose 環境

- `compose.yaml` 放共用設定
- `compose.dev.yaml` 放熱更新、原始碼掛載與開發工具
- `compose.prod.yaml` 放正式映像、健康檢查、重啟策略與資源限制
- 正式環境不要掛載原始碼，也不要把密碼寫進 Compose 或 Git

## 6. 建立資料庫管理流程

- 使用 migration，而不是手動修改資料表
- 準備 seed／測試資料
- 設計正式環境的備份與還原方式

## 7. 完成一條垂直功能

- 從資料庫、API 到前端畫面全部跑通
- 先驗證登入、錯誤處理、權限和部署方式，再大量擴充功能

## 8. 建立 CI/CD 與文件

- PR 自動執行 lint、測試和 build
- 合併後建置 Docker image；正式部署最好保留人工核准
- README 說明需求、設定、啟動、測試、migration、部署與常見問題
